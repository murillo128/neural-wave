# Labs Overview

The labs are executable C++ mini-programs. Each lab corresponds to a lesson and turns one concept into a small inspectable program.

The labs are intentionally educational, not optimized. They do not implement real production LLM internals.

Build instructions may vary per lab, so read each lab's README and docs page before running it.
